TWENE: Table for When Everything is Not as Expected

At a scene or location change, ask if things are as expected. On a no, roll TWENE to shape the twist.

TWENE Table and Guidance
d10 Result
1Increase simple element
2Decrease simple element
3Add simple element
4Remove simple element
5Increase major element
6Decrease major element
7Add major element
8Remove major element
9Wild positive
10Wild negative

Simple element: minor scene color with little direct mechanical impact.

Major element: a key factor driving the scene, threat, objective, or leverage.

Wild results are intentionally open-ended; use a Portent or prompt roll if no clear idea appears.
